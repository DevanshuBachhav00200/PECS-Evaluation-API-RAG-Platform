## 7. Known gaps

What this suite does **not** cover, stated so nobody infers it from a green run:

- **No live-model tests.** Every LLM interaction is a scripted fake (TEST-006's acceptance criterion). Grading quality against a real model is BENCH-004/BENCH-010's job and requires `ANTHROPIC_API_KEY`.
- **No container tests.** The Dockerfile and compose invariants are checked statically (`tests/member6/test_deployment.py`); the build, health, persistence and secret checks need a Docker engine and are run by `python -m scripts.verify_container`.
- **No load or concurrency testing.** The rate limiter is unit-tested; behaviour under sustained concurrent traffic is unmeasured.
- **Workstream B modules are absent**, so TEST-001 covers the annotation-layer and vector-store-layer validation that exists rather than Member 1's `schema.py` / `quarantine.py`. See `docs/known_issues_and_limitations.md`.
