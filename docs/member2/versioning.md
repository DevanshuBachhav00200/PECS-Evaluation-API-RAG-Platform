# Annotation Versioning

Recommended annotated dataset tags:

- `pecs-annotations-v0.1` — first executable Member 2 pipeline
- `pecs-annotations-v0.2` — after SME rubric review
- `pecs-annotations-v1.0` — after gold/validation sign-off and Member 3 handoff

Never rewrite an already-published audit event. New corrections should append a new event.
